Connect Spotify needs one callback URL configured first

Spotify rejected the login start because the redirect URI must exactly match one of the callback URLs registered in your Spotify developer app.

Use this callback URL

{{ redirect_uri }}

Add that exact URL in your Spotify app settings under Redirect URIs, then set the same value in your environment:
