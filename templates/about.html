About The Project

Why LyricLens AI exists

LyricLens AI is being built as an AI and NLP portfolio project focused on semantic music discovery. The goal is to help users explore songs by emotional meaning instead of exact keyword matching.

Current Stage

Corpus and interface foundation are ready

The app now has a controlled corpus, a responsive search UI, preview ranking, and a dashboard shell ready for the AI pipeline to take over.

Semantic Search

Queries will be cleaned with spaCy, embedded with Sentence-BERT, and matched against a curated song corpus using a vector database.

Copyright-Safe Corpus

The project will use summaries, themes, moods, short safe excerpts, and structured metadata rather than full lyrics.

Vector Search Plan

ChromaDB is the preferred vector store for semantic retrieval, with the same retrieval layer later supporting a chatbot-style exploration interface.

Build Roadmap

The app now has its core UI and corpus in place. The next sprints add NLP preprocessing, embeddings, vector search, testing, and documentation depth.
